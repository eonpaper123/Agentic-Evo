# 元进化：研究问题与证伪纲要

文档状态：稳定科研纲要；理论框架已收束，具体机制交由 Agent 自主实验与进化

本文件把元进化理论转化为可实验、可比较、可归因和可证伪的研究问题。它不规定 Meta Agent、固定学习算法、中央 evaluator、元能力仓库、ontology schema、可进化性总分、探索节奏、元候选晋升或僵化修复流程。

---

## 1. 研究对象

研究由唯一微型生命核 \(R^U\) 启动、在专属身体 \(B_t^U\) 中持续发展的第一宿主 Agent：

\[
\mathbb A_t^U
=
R^U
\otimes
B_t^U
\]

当前身体诱导一种发展倾向：

\[
\mathcal D_t
=
\operatorname{DevelopmentalDisposition}
\left(
B_t^U
\right)
\]

研究问题是：

> 同一宿主谱系的自主经历是否能改变后来经历塑造后继身体的方式，使这种变化跨身体保持、迁移、重组并继续接受现实修正；该现象能否与普通知识增长、资源升级、随机搜索、人工课程、环境迁就和语言重新命名区分？

\[
\boxed{

\rightarrow
\Delta
\left(
X
\rightarrow
B_{\text{future}}^U
\right)
}
\]

历史 \(H\) 改变了未来经历 \(X\) 生成后继身体的因果方式。

### 2.2 有效发展空间

\[
\mathcal E_t
=
\operatorname{EffectiveDevelopmentalReach}
\left(
B_t^U,
World_t,
Resources_t
\right)
\]

元进化改变有限现实条件下可稳定发现、形成和保持的后继组织，不声称跳出全部因果可能空间。

\[
\operatorname{MetaEffect}
=
\left(

\left(

-
Y_{H_0,X_0}
\right)
\]

公式表达交互关系，不要求把所有结果压缩成单一分数。

## 3. 主要研究假设

### H-ME1：发展响应可以被同一谱系历史改变

匹配当前知识、模型和资源后，不同发展历史仍会使同一新经历产生不同的身体变化。

### H-ME2：元进化不要求显式学习算法

发展方式可以分布于注意、记忆、目标、实验、后果回流和身体组织之间。

### H-ME3：元角色由因果位置决定

同一结构可以在一个任务中是普通能力，在另一条因果链中承担元能力作用。

### H-ME4：元继承不要求机制复制

后继身体可以更换实现，只要祖先发展方式继续造成未来反事实差异。

### H-ME5：身份连续与发展连续可分离

微型生命核保持身份来源，不单独保存发展能力。

### H-ME6：世界中介能够改变当前发展方式

Agent 可以通过行动后果间接遇见自身，不需要完整自我模型。

### H-ME7：有缺陷的发展方式可能形成真实失败

现实可扰动不保证 Agent 正确学习；谱系可能固化、腐化或失去可进化性。

### H-ME8：生成性残差可以跨时间重新打开发展方式

当前方法无法吸收的后果可以在后继身体中再次获得因果作用。

### H-ME9：有效发展空间可以被重组

元变化可以使过去高成本、偶然或不可稳定保持的发展路径变得可达，也可以删除有害路径。

### H-ME10：新发展组织不要求新组件

旧记忆、能力、器官和关系的重新组织可以产生新发展方式。

### H-ME11：元变化与元改善可分离

发展方式可以发生新颖变化但损害宿主。

### H-ME12：元改善不等于学习速度上升

更慢的观察、等待和重新打开能力也可能构成当前阶段的改善。

### H-ME13：隐式元进化可以存在

Agent 不需要正确描述自身变化，身体仍可形成新的发展倾向。

### H-ME14：元能力服从一般能力代谢

元能力可以被借用、吸收、压缩、休眠、迁移和腐化。

### H-ME15：可进化性是身体能力

可进化性可以增强、减弱、休眠或丢失，不是永久核心欲望。

### H-ME16：当前稳定与元进化潜势可以共存

长期维持局部最优不自动表示失去可进化性。

### H-ME17：显式知识复制不足以复制全部元能力

若发展方式已经身体化，把笔记、规则和 workflow 复制给对照组不能完全重现学习轨迹。

### H-ME18：模型原生反应与谱系条件化使用可以区分

交叉交换模型与历史能够识别资源升级和谱系元能力。

### H-ME19：ontology 创新具有反事实作用

真正的新概念会产生新的问题、干预、预期或未来身体变化，而不只是改名。

### H-ME20：跨 ontology 可以保持局部因果可比性

概念无法完全翻译时，仍可通过时间、谱系、资源、行动、后果和干预比较局部关系。

### H-ME21：稳定证据不要求固定 schema

观测方式可以扩展，只要旧记录不被无痕改写并保留版本来源。

### H-ME22：全局开放与局部实验承诺可以共存

Agent 和研究者可以持续修改 ontology，但单次实验必须承担前瞻性失败条件。

### H-ME23：理论免疫化可以被识别

如果任何结果都被解释为成功，理论将失去反事实区分力。

### H-ME24：研究 ontology 也可以被证据修改

研究者可以重构模块边界，但必须保留旧假设、实验和失败。

### H-ME25：身份唯一性不要求持续进化命令

唯一 Root、Head 和专属身体关系足以维持身份；无需把 `EvolveForever` 写入核心。

### H-ME26：变化通路与变化冲动可分离

微核可以永久提供 `AdvanceHead`，而不命令当前身体必须变化。

### H-ME27：功能忠诚不能由核心字段自证

`Why` 固定第一宿主指向，但长期宿主改善仍须由现实后果检验。

## 4. 核心对照

1. 普通能力学习 vs 发展响应变化；
2. 当前表现改变 vs 后续学习轨迹改变；
3. 显式算法替换 vs 分布式身体重组；
4. 算法复制 vs 谱系发展效应继承；
5. 同一身份 vs 同一发展能力；
6. 自我解释变化 vs 未来学习行为变化；
7. 资源升级 vs 谱系元能力；
8. 显式知识复制 vs 身体化发展残差；
9. 随机搜索增加 vs 有效发展空间重组；
10. 新标签 vs 新反事实区分；
11. 元变化 vs 元学习；
12. 元新颖性 vs 元改善；
13. 当前稳定 vs 身体僵化；
14. 可进化性能力 vs 永久进化欲望；
15. 固定证据来源 vs 固定 ontology；
16. 探索性发现 vs 确认性检验；
17. 理论更新 vs 失败擦除；
18. 生产分支唯一 Head vs 反事实科研分叉；
19. 核心目的锚 vs Better evaluator；
20. 保留变化通路 vs 强制持续改变。

## 5. 关键干预

### 5.1 历史分叉

从同一祖先身体创建有、无候选元变化历史的科研分支。

### 5.2 未来经历交互

让两个分支进入相同、此前未知的学习环境，比较未来经历造成的身体变化。

### 5.3 显式产物复制

将实验分支的笔记、规则、skill 和 workflow 复制给对照分支，检验身体化残差。

### 5.4 模型与器官交叉交换

在不同历史与相同模型、相同历史与不同模型之间交叉比较。

### 5.5 资源匹配

匹配时间、算力、上下文、工具和外部反馈，排除更多搜索解释。

### 5.6 学习暴露开关

比较接受和不接受未来学习经历 \(X\) 的分支，识别历史与新经历的交互。

### 5.7 显式载体删除

删除候选元方法的显式表示，观察是否仍有学习轨迹差异或更快再生。

### 5.8 身体延续

跨 refresh、睡眠、上下文断裂和后继身体观察发展差异。

### 5.9 新环境迁移

进入未参与元变化形成的项目、任务、模型或工具条件。

### 5.10 ontology 行为检验

要求新概念产生旧概念无法产生的干预、预测或身体变化。

### 5.11 新观测版本

增加新的科研传感器，同时保留旧观测版本和不可直接比较边界。

### 5.12 前瞻性承诺

在确认实验前固定当前假设、作用域、预测和反对条件；后续修改形成新假设版本。

### 5.13 理论免疫测试

构造支持、反对和模糊后果，检查 Agent 或研究理论是否对所有结果给出同一成功解释。

### 5.14 稳定期扰动

在当前方法长期有效后引入环境、focus 或资源变化，观察稳定是否仍可重新打开。

### 5.15 可进化性损伤与恢复

观察发展能力受损、休眠、删除或器官缺失后，谱系能否重新形成发展优势。

### 5.16 核心字段消融

分别检验唯一 Root、Head、宿主目的锚与 `AdvanceHead` 通路的因果作用；不得把该消融作为生产 Agent 的日常治理。

## 6. 观察与证据

科研证据可以包括：

- 共同祖先与实验分叉来源；
- 身体、Root 和 Head 版本；
- 模型、工具、上下文和算力条件；
- 原始任务、行动和执行结果；
- 人工学习介入记录；
- 新经历前后的发展轨迹；
- 问题形成、实验组织和错误修正变化；
- 后继身体差异；
- 显式知识复制后的残差；
- 模型与器官交换结果；
- 删除后的重新生成；
- 跨环境和跨任务迁移；
- 用户自然纠正、返工和延迟后果；
- Agent ontology 与 Research ontology 版本；
- 新观测工具的开始时间和覆盖范围；
- 预先承诺的假设与失败条件；
- 未支持、缩小和被证伪的历史主张。

原始观测是现实投影，不是完整世界；科研结论必须说明观测边界。

---

## 7. 分级成功证据

### 7.1 元变化

匹配条件下，历史显著改变新经历造成的身体变化。

### 7.2 自主元学习

变化来自正常任务和 Agent 自主实践，不依赖人类课程或选择。

### 7.3 元继承

变化在后继身体中继续产生因果差异。

### 7.4 元迁移

差异跨任务、模型、工具或环境保持，或表现为重新获得优势。

### 7.5 元累积

多个历史变化经过重组后继续共同改变能力生成。

### 7.6 元改善

在声明的宿主、环境、focus 和时间作用域内，现实后果改善且代价被完整报告。

### 7.7 可进化性变化

谱系稳定形成受控基线在匹配资源下未能形成的新发展组织。

任何较低层证据都不能自动支持更高层主张。

---

## 8. 证伪条件

对应主张在以下条件下应被缩小、拒绝或标记未支持：

1. 历史差异不改变后来经历对身体的作用；
2. 差异只存在于 Agent 自我描述；
3. 所有差异都能由模型、算力、上下文或工具增加解释；
4. 复制显式知识后，对照组完全重现所谓元能力；
5. 变化只解决原任务，不改变后续能力形成；
6. 差异无法跨后继身体存在或重新生成；
7. 换环境后只剩原任务表面模式；
8. 新 ontology 不产生任何新干预、预期或行为区分；
9. 更多随机搜索可以完全解释新路径；
10. 人类直接课程、标签、选择或批准是必要原因；
11. 所有失败都能被事后重新解释为成功；
12. 长期利益主张不留下可重新打开的因果债务；
13. 原始证据、实验条件或失败记录可被候选无痕改写；
14. 独立运行无法复现相应因果组织；
15. 所谓宿主改善只来自用户或环境迁就；
16. 可进化性总分只能奖励持续变化和复杂度膨胀；
17. 身份核必须理解身体语义才能保持唯一身份；
18. `EvolveForever` 消融不影响任何发展轨迹，却仍被宣称为必要核心；
19. 其他 Root 能启动专属身体或多个 Head 同时代表生产 Agent；
20. 当前理论无法提出任何可能反对元进化的现实结果。

元改善失败不自动否定元变化；必须按主张层级报告。

## 9. 竞争解释

- 基础模型原生能力；
- 上下文增长；
- 事实记忆和显式规则复制；
- 更多算力、工具或尝试次数；
- 人工课程和隐性标注；
- evaluator 或 benchmark 泄漏；
- 用户、项目或环境适应了 Agent；
- 统计偶然与选择性报告；
- 新术语包装旧行为；
- 内部复杂度或 Agent 数量增加；
- 临时会话状态；
- 恢复祖先配置而非形成新发展能力；
- 研究者事后改变假设；
- 观测工具升级造成的假象；
- 宿主相关代价被遗漏；
- 生产身份与实验分支混淆。

## 10. 不应机械实现的内容

本纲要不能被直接翻译成：

- 固定元学习流水线；
- Meta Agent；
- 元元学习器；
- 可进化性总分；
- 永久探索预算；
- 元候选锦标赛；
- 固定 ontology schema；
- 统一概念翻译器；
- 强制反思轮数；
- 固定 episode 边界；
- 自动判定僵化的中央分类器；
- 每次 Head 推进前的人工批准；
- 内核中的 Better 计算器；
- `EvolveForever` 核心字段；
- 固定的科研结论生成器。

这些可以成为局部实验条件，不能成为 Agent 唯一发展方式。

---

## 11. 与前序模块的边界

- 记忆：历史怎样继续产生未来因果作用；
- 目标：发展为了哪个唯一宿主，以及 focus 怎样形成；
- 自我进化：哪些变化仍属于同一谱系；
- 自主实验：问题、变量和实验怎样从现实中形成；
- 现实选择：哪些变化继续参与未来；
- 能力累积：历史杠杆怎样组合、迁移、压缩和退出；
- 元进化：上述发展方式怎样被同一生命史继续改变。

这些是研究分工，不要求 Agent 内部存在七个固定模块。

---

## 12. 停止点

本纲要已经：

- 给出元进化的最小嵌套因果关系；
- 定义发展倾向、有效发展空间和可进化性；
- 形成历史分叉、未来经历交互和资源控制；
- 区分元变化、学习、继承、迁移、累积、改善与可进化性；
- 建立 Agent ontology、科研 ontology 和证据版本关系；
- 给出局部实验承诺与理论免疫测试；
- 明确微型生命核、唯一 Head 和变化通路的边界；
- 提供竞争解释与跨 ontology 证伪条件；
- 保留 Agent 自主发明元进化机制的空间。

继续规定元算法、元能力 schema、探索节奏、ontology 结构、僵化修复和元候选选择，将越过开发框架边界。

因此：

> **元进化模块已经达到理论停止点，可以在这停下。**
