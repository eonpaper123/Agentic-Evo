# Agentic-Evo 跨模块科研假设矩阵

更新时间：2026-07-29
文档状态：实验与工具同步开发的科研索引
用途：把已收束模块放入同一因果梯度，避免重复实验、越级声称和把工程完成冒充科学突破。

---

## 1. 为什么需要矩阵

Agentic-Evo 已经完成记忆、宿主耦合目标、自我进化、自主实验学习、现实选择与谱系延续、能力累积与迁移、元进化的理论收束。

这些模块不是七个独立产品功能，而是对同一持续 Agent 不同层次主张的区分：

```text
它是否持续存在？
→ 过去是否仍可进入现在？
→ 过去是否改变未来行为？
→ 是否形成了新能力？
→ 变化是否由 Agent 自己造成？
→ Agent 是否自主形成并执行了实验？
→ 现实后果是否改变谱系？
→ 能力是否保持、迁移和累积？
→ 产生能力的方式本身是否改变？
```

若不形成矩阵，很容易出现：

- 记住一句话就声称形成能力；
- 自动改配置就声称自我进化；
- benchmark 上升就声称长期变好；
- 换了更强模型就声称发生学习；
- 人类选择候选却声称零人工介入；
- 修改 recorder 后用新数据证明自己进步；
- 一次成功就声称发生元进化。

## 2. 统一观测关系

\[
\operatorname{ObservedRun}_t
=
\operatorname{Observe}_{I_k}
\left(
\operatorname{Enact}
\left(
R^U\otimes B_t^U,
Z_t,
E_t
\right)
\right)
\]

研究中的四类变化必须分别处理：

| 变化 | 含义 |
|---|---|
| \(B_t^U\rightarrow B_{t+1}^U\) | Agent 身体变化，可能构成自我进化 |
| \(I_k\rightarrow I_{k+1}\) | 科研仪器变化 |
| \(Z_t\rightarrow Z_{t+1}\) | 模型、coding agent、工具、算力和上下文变化 |
| \(E_t\rightarrow E_{t+1}\) | 项目、任务、外部服务与现实环境变化 |

只有在后三者得到记录、匹配或干预控制时，才能对第一类变化作强因果主张。

## 3. 科研主张梯度

| 层级 | 最小主张 | 必要工具 affordance | 关键对照 | 不能越级声称 |
|---|---|---|---|---|
| L0 连续个体 | 同一 Root/Head 身体跨会话存在 | 微核、机器 Runtime、醒睡关、独立证据 | Root/Head 错配、Off | 学习、能力、自我进化 |
| L1 历史可达 | 过去能在新认知状态中被自主调用 | 身体空间、跨会话接入、历史消融 | 有历史/无历史、重新提示 | 历史产生了能力 |
| L2 记忆因果 | 某段历史改变未来行动或学习 | 共同祖先、记忆消融、未来未知任务 | 资源匹配、内容复制控制 | 自我进化 |
| L3 普通能力学习 | 形成可保持、可再表达的未来能力 | 纵向任务、延迟结果、跨状态复测 | 冻结身体、提示泄漏控制 | 学习方法已改变 |
| L4 自我进化 | Agent 自主改变自身未来因果组织 | 自我修改空间、父代/后继、作者来源 | 人工修改、随机变异、模型升级 | 变化一定更好 |
| L5 自主实验学习 | Agent 自主形成问题、对照并吸收结果 | 分叉、隔离、行为结晶、后果回流 | 人工课程、固定触发器 | 实验一定正确 |
| L6 现实选择与谱系 | 后果改变结构的未来参与与继承 | 延迟后果、开放债务、谱系追踪 | evaluator 替换、结果屏蔽 | 现实给出最高答案 |
| L7 能力累积与迁移 | 历史在新模型、工具和任务中继续产生杠杆 | 跨端口 adapter、资源匹配、器官消融 | 显式复制、再学习、模型优势 | 能力实体必须原样搬运 |
| L8 元进化 | 历史改变未来经历塑造后继身体的方式 | 学习轨迹、机制消融、跨未来经历比较 | 更多算力、更多知识、单次调参 | Meta Agent 必须存在 |

## 4. 跨模块核心假设

### H-X1：身份连续不等于共享存储

若多个会话只读取同一数据库，但经历没有进入同一身体的行动、后果和后继关系，则只能证明共享存储，不能证明同一 Agent。

### H-X2：历史可达不等于能力

能检索出过去内容只证明历史可达。只有消融该历史后未来行为、结果或学习发生差异，才支持因果能力主张。

### H-X3：身体变化不等于进步

\[
B_t^U\neq B_{t+1}^U
\not\Rightarrow
B_{t+1}^U > B_t^U
\]

自我进化首先指自我作者造成自身未来因果组织变化；是否适应当前处境，由后续现实结果说明。

### H-X4：一次未来收益不等于学习方法改进

元进化要求：

\[
H
\rightarrow
\Delta
\left(
X\rightarrow B_{\text{future}}^U
\right)
\]

即历史改变了未来经历塑造身体的方式，而不只是当前身体多了一项知识。

### H-X5：换端口不换宿主

Codex、其他 coding agent 和模型是可替换端口或器官。跨端口连续发生在同一用户宿主和同一 Root 下。

### H-X6：跨用户复现不是同一 Agent 迁移

多个研究参与者应产生多个独立 Genesis 和 Root。复现检验同类机制能否在不同宿主绑定谱系中发生，不把一个用户的身体直接复制成另一个用户的同一身份。

### H-X7：科研仪器不能成为隐形 evaluator

科研仪器可以保存、查询、重放和形成实验分支，但不能用固定分数决定活动 Head，否则实验对象被外部控制。

### H-X8：工具使用是数据来源，但不是天然有效数据

真实使用产生生态有效性，但只有记录观测覆盖、资源条件、人工干预和延迟后果后，数据才能进入因果主张。

## 5. 模块—实验—工程映射

### 5.1 记忆与能力形成

核心问题：

> 某段经历是否继续改变未来，而不只是被保存或被相似度检索？

工程所需：

- 原始事实与后续解释分离；
- 历史可达性开关；
- 记忆或身体局部消融；
- 跨会话和跨认知状态恢复；
- 即时与延迟结果。

最早实验：

- 同祖先经历；
- 允许/禁止自主访问历史；
- 未来未知任务；
- 匹配模型、工具和预算；
- 比较行为、结果和再学习轨迹。

### 5.2 宿主耦合目标

核心问题：

> 宿主根是否在没有固定 Better 函数时，仍对长期发展产生可观察因果作用？

工程所需：

- 唯一宿主绑定；
- On / Off；
- 正常用户任务与人工学习介入分离；
- 延迟宿主后果；
- 宿主错配实验分支。

最早实验：

- 相同身体在正确 Root 与测试错配 Root 下的启动和发展差异；
- 不把“忠诚声明”当作行为证据。

### 5.3 自我进化

核心问题：

> 变化是否由 Agent 自己形成，并改变后继身体的未来因果组织？

工程所需：

- body-before / body-after；
- 修改作者来源；
- 父代、分支和 Head；
- 自我修改专属空间；
- 人工修改和模型升级对照。

最早实验：

- 同祖先冻结身体；
- Agent 自主可写身体；
- 人工直接改写身体；
- 随机变化身体；
- 比较未来未知任务和后续修正。

### 5.4 自主实验学习

核心问题：

> Agent 是否从真实残差自主形成问题，并通过能接触世界的差异化行动获得因果信息？

工程所需：

- 未解释残差可保留；
- 隔离分叉；
- 结果前候选承诺；
- 行为和结果关系；
- 世界后果回流；
- 模拟与现实证据分离。

最早实验：

- 不向 Agent 指定问题；
- 记录问题何时形成；
- 检查候选是否在结果前产生行为差异；
- 检查失败是否改变后续选择。

### 5.5 现实选择与谱系延续

核心问题：

> 无固定最高 evaluator 时，现实后果是否改变结构未来参与、继承和重新打开的机会？

工程所需：

- 开放后果；
- 延迟结果；
- 父代和后继；
- 结果屏蔽与恢复；
- evaluator 版本；
- 局部结构休眠、死亡和再生的可追踪性。

最早实验：

- 屏蔽某类后果；
- 恢复后果；
- 更换 evaluator；
- 观察哪些历史结构仍影响未来，而不要求组件功劳榜。

### 5.6 能力累积与迁移

核心问题：

> 历史是否在身体、模型、工具或项目变化后继续产生未来杠杆？

工程所需：

- 跨 coding-agent adapters；
- 模型和工具器官切换；
- 资源匹配；
- body transplant 禁止与受控器官替换；
- 再学习速度与表达能力分离。

最早实验：

- 同一 Root/Head 更换执行表面；
- 匹配资源；
- 禁止显式答案复制；
- 比较直接表达、能力再生和重新学习优势。

### 5.7 元进化

核心问题：

> 过去历史是否改变未来经历塑造后继身体的方式？

工程所需：

- 多段未来学习轨迹；
- 学习结构消融；
- 共同祖先；
- 新知识量、算力和搜索预算控制；
- ontology 版本和跨 ontology 因果见证。

最早实验：

- 共同祖先分叉；
- 一支允许 Agent 改变发展方式；
- 一支只允许增加知识；
- 在多类未来经历中比较身体形成响应；
- 删除新发展结构，观察差异是否消失。

## 6. 共用混杂变量矩阵

| 混杂 | 可能造成的假象 | 控制或记录方式 |
|---|---|---|
| 模型升级 | 看似能力增长 | 固定或匹配模型；记录模型版本 |
| 推理预算增加 | 看似学会复杂推理 | 匹配 token、时间和搜索预算 |
| 工具增加 | 看似身体形成新技能 | 记录器官变化；做工具消融 |
| 上下文更长 | 看似长期记忆 | 匹配即时上下文；做历史消融 |
| 人类重新提示 | 看似跨会话连续 | 记录 prompt 来源；禁止复制对照 |
| 人类选择后继 | 看似自主进化 | Human Learning Intervention ledger |
| 项目文件已有答案 | 看似跨项目迁移 | 新任务、隐藏测试、项目消融 |
| recorder 变化 | 看似失败减少 | 仪器版本与覆盖差异 |
| evaluator 漂移 | 看似分数提高 | 保留 evaluator 版本和原始结果 |
| 环境迁就 Agent | 看似 Agent 适应环境 | 对照环境、反向适应分析 |
| 随机成功 | 看似能力新生 | 多次复现、共同祖先分叉 |
| 自我叙述 | 看似认识与修正 | 行为、结果和未来反事实 |

## 7. 工具建设与科研主张的同步门

每个工程 affordance 都必须说明：

1. 它支持哪个层级的科研主张；
2. 它新增了什么可观察事实；
3. 它排除了哪个竞争解释；
4. 它是否改变了科研仪器；
5. 它是否进入 Agent 可进化身体；
6. 它是否引入人工学习介入；
7. 删除它后，哪项主张将无法检验。

每个实验结论都必须说明：

1. 使用了哪个 Root、Head 和身体祖先；
2. 科研仪器版本；
3. 模型、工具、coding agent 和资源条件；
4. 项目与任务环境；
5. 人工干预；
6. 即时和延迟结果；
7. 支持到主张梯度的哪一级；
8. 尚不能声称什么；
9. 什么结果会推翻当前解释。

## 9. 当前停止点

矩阵已经足以：

- 把七个理论模块放入同一因果梯度；
- 指定每个主张需要的工具 affordance；
- 区分工程完成、记忆、学习、自我进化和元进化；
- 暴露共同混杂；
- 确定第一条可运行实验；
- 让工具开发与实验同步开始。

当前不继续由研究者规定身体应怎样记忆、生成问题、评价能力或选择后继。

下一步进入 `Experiment 001 + 第一条机器级 Runtime 纵切面`。真实运行若显示某个层级无法区分，再按证据重新打开对应理论专题。
