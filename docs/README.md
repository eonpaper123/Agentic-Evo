## 文档原则

- 纲领文件保持最终产品与科研目标的一致定义。
- 开发框架保存研究方法、Agent 自由空间、科学可观察性与开发决策标准。
- 专题文件保留公式、关系图、推导过程、尚未解决的问题和观点修正。
- 现有协议、模型和工具只作为实验材料，不能反向缩小最终科研目标。
